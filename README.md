# Auktionshaus Hohenstaufen – Homepage (Entwurf)

Erste Version der neuen Startseite zur Abstimmung mit dem Kunden.

- `index.html` – Startseite (eine Datei, keine Abhängigkeiten außer Google Fonts „Inter Tight“)
- `journal.html` – Journal mit den Presseberichten 2013–2019
- `medien/` – Radio-/Videobeiträge und PDF
- `bilder/` – aufbereitete Objektfotos (Montage auf Studio-Hintergrund, Platzhalter bis zur finalen Fotolieferung)

**Hinweis:** Einige Kennzahlen und Termine sind Beispielwerte und müssen vor dem Livegang geprüft werden.
